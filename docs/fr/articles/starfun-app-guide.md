# Guide de l’APK StarFun : égaliseur et micrologiciel pour les répliques d’AirPods Huilian

StarFun est l’application compagnon des répliques d’AirPods équipées de chipsets **Huilian** (247, 277, 377 et 377H3). Elle remplit pour les modèles Huilian le même rôle que [FlyCC](/fr/articles/flycc-app-guide) pour les modèles Airoha et TigerBuilder : elle permet de régler l’égaliseur et de mettre à jour le micrologiciel. Si vous possédez une réplique Huilian, comme les AirPods Pro 3 V7 Huilian ou les Pro 2 V5.4, StarFun est l’application à installer.

> **Réponse rapide :** StarFun est l’application des répliques d’AirPods équipées de puces Huilian : les AirPods Pro 3 V7 Huilian et V6 Huilian, les AirPods Pro 2 V5.4 et V5.3 Huilian, ainsi que les AirPods 4 V2 Huilian. Téléchargez-la sous forme d’APK Android ou depuis l’App Store iOS via [Useful Apps](/fr/useful-apps#huilian). Utilisez-la pour régler l’égaliseur et, uniquement en cas de problème, pour mettre à jour le micrologiciel. Les modèles TigerBuilder utilisent plutôt FlyCC. Si aucune application ne se connecte à vos écouteurs, il s’agit probablement d’une réplique Jieli bas de gamme.

## Quelles répliques utilisent StarFun

Voici les versions pour lesquelles les tableaux de versions du guide indiquent StarFun comme application de réglage de l’égaliseur et des paramètres :

| Modèle | Version | Chipset | Connexion iCloud |
| :--- | :--- | :--- | :--- |
| AirPods Pro 3 | V7 Huilian | Huilian 377H3 | ✅ |
| AirPods Pro 3 | V6 Huilian | Huilian 247 | ✅ |
| AirPods Pro 2 | V5.4 Huilian | Huilian 377 | ✅ |
| AirPods Pro 2 | V5.3 Huilian | Huilian 277 Pro Max | ✅ |
| AirPods 4 | V2 Huilian | Huilian 247 | ✅ |

Le tableau des AirPods 3 indique également StarFun pour la V1.2 (Huilian A10), mais les vendeurs de confiance ne proposent actuellement aucun AirPods 3.

Ces cinq modèles sont aussi les modèles du guide compatibles avec la connexion iCloud. Cette fonction est exclusive aux répliques équipées d’une puce Huilian ; si vous avez acheté une paire pour passer d’un appareil Apple à un autre, StarFun est l’application qu’il vous faut. Comparez les versions sur les pages des modèles [Pro](/fr/version-info/pro) et [AirPods](/fr/version-info/airpods).

## Télécharger StarFun pour Android ou iOS

StarFun existe en deux versions, toutes deux accessibles depuis [Useful Apps](/fr/useful-apps#huilian) :

- **Android :** [APK StarFun](https://airreps.link/starfun)
- **iPhone :** [StarFun sur l’App Store](https://airreps.link/istarfun)

La version Android est un APK, et non un téléchargement depuis Google Play. Si Android bloque l’installation, activez **Installer des applications inconnues** (également appelé **Installation d’applications inconnues**) pour votre navigateur ou votre gestionnaire de fichiers. Cette option se trouve généralement dans les paramètres, sous Sécurité ou Accessibilité. Ouvrez ensuite le fichier `.apk` téléchargé et appuyez sur **Installer**.

Avant d’ouvrir StarFun, connectez les écouteurs à votre téléphone depuis les paramètres Bluetooth habituels.

## Régler l’égaliseur

Le réglage de l’égaliseur peut varier selon le vendeur ; une même version peut donc avoir un son différent d’un lot à l’autre. Le guide recommande StarFun pour régler l’égaliseur des appareils Huilian, tout comme FlyCC est recommandé pour les appareils TigerBuilder et BullSuper pour les appareils HR. Sur les AirPods 4 V2 Huilian, les profils d’égalisation personnalisés StarFun se synchronisent directement avec iOS.

Vous ne voulez pas tout régler depuis le début ? Les membres de la communauté partagent leurs propres réglages d’égalisation sur Discord (voir la fin de ce guide). Pour savoir comment sonnent les répliques dès leur sortie de la boîte, consultez la page [Qualité sonore](/fr/introduction/sound-quality).

## Mettre à jour le micrologiciel avec StarFun

Commencez par suivre la règle d’or de la communauté : **si ça marche, n’y touchez pas.** Les mises à jour du micrologiciel sont principalement publiées pour corriger les problèmes provoqués par les mises à jour majeures d’iOS ou les bogues matériels graves. Si vos écouteurs se connectent sans problème et produisent un son correct, une mise à jour ne fait qu’ajouter le risque de les rendre inutilisables.

Si une mise à jour est nécessaire, commencez par suivre ces consignes de sécurité :

1. Chargez les deux écouteurs et le boîtier à plus de 80 %.
2. Laissez le boîtier branché pendant la mise à jour.
3. Laissez les deux écouteurs dans le boîtier, couvercle ouvert.
4. Gardez l’écran de votre téléphone allumé afin d’éviter que le transfert ne s’interrompe.

Procédez ensuite à la mise à jour dans StarFun :

1. Assurez-vous que les écouteurs sont connectés à votre téléphone et que le couvercle est ouvert.
2. Ouvrez **StarFun** et appuyez sur l’icône **Paramètres / Micrologiciel**.
3. Comparez la version actuelle du micrologiciel à la dernière version disponible dans le cloud.
4. Appuyez sur **Mettre à niveau**. L’application écrit les blocs de configuration les uns après les autres.
5. Après le redémarrage des écouteurs, oubliez-les dans le menu Bluetooth de votre téléphone, puis effectuez une réinitialisation logicielle.

N’utilisez StarFun qu’avec des écouteurs Huilian. Installer un micrologiciel prévu pour un autre chipset peut rendre les écouteurs inutilisables ; un micrologiciel conçu pour une puce Airoha rend immédiatement inutilisable une carte Huilian.

Si la mise à jour reste bloquée sur un pourcentage pendant plus de 5 minutes, ne fermez pas le couvercle et ne retirez pas les écouteurs. Réessayez ou redémarrez l’application sans déplacer les écouteurs. Si ceux-ci ne répondent plus du tout, effectuez la réinitialisation matérielle décrite dans [Comment réinitialiser de faux AirPods](/fr/articles/how-to-reset-fake-airpods), puis rouvrez StarFun. Dans la plupart des cas, la mise à jour peut être relancée depuis 0 %. Le [guide de mise à jour du micrologiciel](/fr/articles/how-to-update-fake-airpods-firmware) couvre tous les chipsets.

## StarFun ne trouve pas vos écouteurs ?

Suivez ces étapes dans l’ordre :

- **Jumelez-les d’abord dans les paramètres Bluetooth.** StarFun a besoin que les écouteurs soient déjà connectés à votre téléphone.
- **Vérifiez la puce.** StarFun est destinée aux modèles Huilian. Les modèles TigerBuilder (Airoha) utilisent FlyCC, et les modèles HR utilisent BullSuper. Pour identifier votre puce, essayez une à une les applications de la page [Useful Apps](/fr/useful-apps) et vérifiez laquelle se connecte.
- **Aucune application ne se connecte ?** Votre paire est probablement une réplique très bas de gamme dotée d’un chipset Jieli, non pris en charge par les applications de la communauté. Les vrais AirPods Apple ne répondent pas non plus à ces applications.
- **La connexion ne cesse de se couper ?** Videz le cache d’appairage en réinitialisant le contrôleur à l’aide du [guide de réinitialisation](/fr/articles/how-to-reset-fake-airpods). Pour les problèmes d’appairage en général, consultez [Les faux AirPods ne se connectent pas](/fr/articles/fake-airpods-wont-connect).
