# AirPods 3

::: tip Разработка прекращена
Производители больше не занимаются активным обновлением этой линейки, поскольку разработка сосредоточилась на более новых моделях. Реплики AirPods 3 по-прежнему остаются отличными устройствами и пользуются популярностью. Если вам нужны самые новые функции и улучшения, обратите внимание на [AirPods 4](/ru/version-info/airpods-4).
:::

**Краткий вывод:** **V1E (Airoha 1562E)** — лучшая реплика AirPods 3 и единственная модель этой линейки, которую продолжают производить. Она поддерживает переключение между несколькими устройствами, пространственное аудио с отслеживанием положения головы, работает от аккумулятора 7–8 часов и поддерживает беспроводную зарядку MagSafe. Перейдите к [ссылкам для покупки AirPods 3](/ru/links/airpods-3).

::: tip Общие особенности AirPods 3
Все модели AirPods 3 имеют открытую анатомическую конструкцию с укороченными ножками, элементы управления воспроизведением Force Sensor, датчик обнаружения наушников в ушах, беспроводную зарядку и поддержку iOS 27 со всплывающим окном на странице «Об устройстве». Обратите внимание: реплики AirPods 3 не поддерживают активное шумоподавление (ANC).
:::
