# AirPods 3

::: tip
Эта линейка продуктов больше не получает активных обновлений от производителей, поскольку разработка переключилась на более новые модели. Реплики AirPods 3 по-прежнему остаются отличными продуктами и пользуются популярностью. Если вам нужны новейшие функции и улучшения, ознакомьтесь с [AirPods 4](/ru/version-info/airpods-4).
:::

**Краткий вердикт:** **V1E (Airoha 1562E)** — лучшая реплика AirPods 3 и единственная активно выпускаемая модель в этой линейке. Она поддерживает переключение между несколькими устройствами, пространственный звук с отслеживанием положения головы, 7–8 часов автономной работы и беспроводную зарядку MagSafe. См. [ссылки для покупки AirPods 3](/ru/links/airpods-3).

::: tip Базовые характеристики всех AirPods 3
Все модели AirPods 3 оснащены открытой посадкой с контурным дизайном и укороченными дужками, элементами управления воспроизведением Force Sensor, определением нахождения в ушах, беспроводной зарядкой и поддержкой iOS 27 со всплывающим окном на странице «Об устройстве». Обратите внимание, что реплики AirPods 3 не поддерживают активное шумоподавление (ANC).
:::
