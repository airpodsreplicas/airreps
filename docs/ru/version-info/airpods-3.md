# AirPods 3

::: warning Сейчас отсутствуют у проверенных продавцов
Ни один из наших проверенных продавцов сейчас не предлагает клоны AirPods 3, поскольку разработка и поставки перешли на более новую модель открытого типа — **[AirPods 4](/ru/version-info/airpods-4)**. Это сравнение сохранено для справки.
:::

**Краткий вывод:** **V1E (Airoha 1562E)** — лучший клон AirPods 3: он поддерживает переключение между несколькими устройствами и пространственное аудио с отслеживанием движений головы, работает 7–8 часов и заряжается беспроводным способом через MagSafe, — но **сейчас отсутствует** у проверенных продавцов. Если нужна доступная модель открытого типа, посмотрите [ссылки для покупки AirPods 4](/ru/links/airpods-4).

::: tip Общие характеристики AirPods 3
Все модели AirPods 3 имеют открытую контурную конструкцию с укороченными ножками, элементы управления воспроизведением с датчиком нажатия Force Sensor, обнаружение уха, беспроводную зарядку и поддержку iOS 27 с всплывающим окном на странице «Об этом устройстве». Обратите внимание: клоны AirPods 3 не поддерживают активное шумоподавление (ANC).
:::
