## Обзор V3 {#v3-overview}

В основе V3 TigerBuilder (TB) лежит высокопроизводительный чипсет **Airoha 1571AM**. Эта модель считается лучшей из доступных реплик наушников открытого типа. Она оснащена двумя гироскопами ST с костной передачей голоса, которые обеспечивают точное отслеживание движений головы в реальном времени для пространственного аудио, функцией распознавания разговора на базе ИИ, автоматически снижающей громкость, когда вы говорите, и отзывчивыми звуковыми эффектами динамика кейса. Также поддерживается плавное переключение между 3 сопряжёнными устройствами и обновление через приложение FlyCC для Android.

## Обзор V2 {#v2-overview}

Наушники уровня V2 обеспечивают надёжное звучание открытого типа; различия зависят от производителя:

- **Huilian 247**: поддерживает iCloud Connect для плавного переключения между устройствами Apple, на которых выполнен вход с одним и тем же Apple ID, адаптивное аудио и приложение Starfun, позволяющее синхронизировать пользовательские профили эквалайзера с iOS.
- **TigerBuilder / HR (Airoha 1563E)**: надёжные модели на каждый день с насыщенным звучанием открытого типа и шумоподавлением с одним микрофоном. В версии HR работает отслеживание движений головы, а модель TB использует фиксированное пространственное аудио и настроена на более выраженные басы.
