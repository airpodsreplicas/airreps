## Обзор V3 {#v3-overview}

V3 TigerBuilder (TB) построена на высокопроизводительном чипсете **Airoha 1571AM** и представляет собой лучшую из доступных копий с открытой конструкцией. В ней установлены два гироскопа ST для костной передачи голоса, обеспечивающие точное отслеживание движений головы в реальном времени для пространственного аудио, а функция распознавания разговора на базе ИИ автоматически снижает громкость, когда вы говорите. Динамик футляра воспроизводит чёткие звуковые эффекты. Модель также поддерживает плавное переключение между тремя сопряжёнными устройствами и обновление через приложение FlyCC для Android.

## Обзор V2 {#v2-overview}

Модели уровня V2 обеспечивают надёжное звучание с открытой конструкцией; небольшие различия зависят от производителя:

- **Huilian 247**: поддерживает iCloud Connect для плавного переключения между устройствами Apple, на которых выполнен вход в один и тот же Apple ID, адаптивный звук и приложение Starfun, в котором можно создавать собственные профили эквалайзера и синхронизировать их напрямую с iOS.
- **TigerBuilder / HR (Airoha 1563E)**: надёжные модели для повседневного использования с выразительным звучанием открытого типа и шумоподавлением с одним микрофоном. В версии HR работает отслеживание движений головы, а модель TB использует фиксированное пространственное аудио и настроена на более выраженные басы.
