## Обзор V3 {#v3-overview}

V3 TigerBuilder (TB) создан на высокопроизводительном чипсете **Airoha 1571AM** и представляет собой лучшую доступную реплику открытого типа. Модель оснащена двумя гироскопами ST с технологией распознавания голосового отпечатка, которые обеспечивают точное отслеживание движений головы в реальном времени для пространственного аудио, функцией распознавания разговора на базе ИИ, которая автоматически снижает громкость, когда вы говорите, и отзывчивыми звуковыми эффектами динамика в футляре. Также поддерживается плавное переключение между 3 сопряжёнными устройствами. Для настройки эквалайзера и обновлений используется приложение FlyCC (Android и iOS).

## Обзор V2 {#v2-overview}

Модели V2 обеспечивают надёжное звучание открытого типа с небольшими различиями в зависимости от производителя:

- **Huilian 247**: поддерживает подключение через iCloud для плавного переключения между устройствами Apple, на которых выполнен вход с одним Apple ID, адаптивное аудио и приложение StarFun, позволяющее создавать пользовательские профили эквалайзера и синхронизировать их непосредственно с iOS.
- **TigerBuilder / HR (Airoha 1563E)**: надёжные модели на каждый день с энергичным звучанием открытого типа и шумоподавлением на одном микрофоне. В версии HR работает отслеживание движений головы, а модель TB использует фиксированное пространственное аудио и настроена с усиленным акцентом на басы.
