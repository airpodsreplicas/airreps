# Руководство по StarFun APK: эквалайзер и прошивка для реплик AirPods на Huilian

StarFun — приложение-компаньон для реплик AirPods на чипсетах **Huilian** (247, 277, 377 и 377H3). Оно выполняет для моделей на Huilian ту же функцию, что [FlyCC](/ru/articles/flycc-app-guide) для моделей на Airoha и TigerBuilder: с его помощью можно настроить эквалайзер и обновить прошивку. Если у вас есть реплика на Huilian, например AirPods Pro 3 V7 Huilian или Pro 2 V5.4, установите StarFun.

> **Краткий ответ:** StarFun — приложение для реплик AirPods на Huilian: AirPods Pro 3 V7 Huilian и V6 Huilian, AirPods Pro 2 V5.4 и V5.3 Huilian, а также AirPods 4 V2 Huilian. Скачайте его в виде APK для Android или из App Store для iOS через страницу [Полезные приложения](/ru/useful-apps#huilian). Используйте приложение для настройки эквалайзера, а обновляйте прошивку только при возникновении неисправностей. Для моделей на TigerBuilder предназначено приложение FlyCC. Если ни одно приложение не подключается к вашим наушникам, скорее всего, это низкокачественная копия на Jieli.

## Какие реплики работают со StarFun

В таблицах версий для перечисленных ниже моделей указано, что для настройки эквалайзера и параметров используется StarFun:

| Модель | Версия | Чипсет | Подключение к iCloud |
| :--- | :--- | :--- | :--- |
| AirPods Pro 3 | V7 Huilian | Huilian 377H3 | ✅ |
| AirPods Pro 3 | V6 Huilian | Huilian 247 | ✅ |
| AirPods Pro 2 | V5.4 Huilian | Huilian 377 | ✅ |
| AirPods Pro 2 | V5.3 Huilian | Huilian 277 Pro Max | ✅ |
| AirPods 4 | V2 Huilian | Huilian 247 | ✅ |

В таблице AirPods 3 приложение StarFun также указано для версии V1.2 (Huilian A10), но проверенные продавцы сейчас не предлагают AirPods 3.

Все эти пять моделей также поддерживают подключение к iCloud. Эта функция есть только у реплик на Huilian, поэтому, если вы купили наушники, чтобы переключаться между устройствами Apple, вам понадобится StarFun. Сравните версии на страницах [Pro](/ru/version-info/pro) и [AirPods](/ru/version-info/airpods).

Если Android блокирует установку, разрешите **Установку из неизвестных источников** (также может называться **Установка неизвестных приложений**) для браузера или файлового менеджера. Обычно эта настройка находится в разделе «Безопасность» или «Специальные возможности». Затем откройте скачанный файл `.apk` и нажмите **Установить**.

Перед запуском StarFun подключите наушники к телефону через обычные настройки Bluetooth.

## Настройка эквалайзера

Звук может различаться у разных продавцов, поэтому одна и та же версия наушников может звучать по-разному в зависимости от партии. Для настройки эквалайзера на устройствах Huilian руководство рекомендует StarFun, так же как FlyCC для TigerBuilder и BullSuper для HR. На AirPods 4 V2 Huilian пользовательские профили эквалайзера StarFun синхронизируются напрямую с iOS.

Не хотите настраивать всё с нуля? Участники сообщества делятся собственными настройками эквалайзера в Discord (см. конец этого руководства). О том, как звучат реплики из коробки, читайте в разделе [Качество звука](/ru/introduction/sound-quality).

## Обновление прошивки через StarFun

Начните с главного правила сообщества: **если всё работает, ничего не трогайте.** Обновления прошивки выпускают главным образом для устранения неисправностей, появившихся после крупных обновлений iOS, или серьёзных аппаратных ошибок. Если наушники подключаются без проблем и звучат как надо, обновление лишь повышает риск вывести их из строя.

Если обновление всё-таки необходимо, сначала выполните следующие меры предосторожности:

1. Зарядите оба наушника и кейс как минимум до 80%.
2. Не отключайте кейс от питания во время обновления.
3. Оставьте оба наушника в кейсе с открытой крышкой.
4. Не выключайте экран телефона, чтобы передача данных не прервалась.

Затем обновите прошивку в StarFun:

1. Убедитесь, что наушники подключены к телефону, а крышка открыта.
2. Откройте **StarFun** и нажмите значок **Настройки / Прошивка**.
3. Сверьте текущую версию прошивки с последней версией в облаке.
4. Нажмите **Обновить**. Приложение последовательно запишет блоки конфигурации.
5. После перезагрузки наушников удалите их из меню Bluetooth телефона и выполните мягкий сброс.

Используйте StarFun только с наушниками на Huilian. Прошивка для другого чипсета может вывести наушники из строя, а прошивка для чипа Airoha мгновенно выведет из строя плату Huilian.

Если обновление зависло на каком-либо проценте более чем на 5 минут, не закрывайте крышку и не вынимайте наушники. Повторите попытку или перезапустите приложение, не вынимая наушники из кейса. Если наушники полностью перестали реагировать, выполните аппаратный сброс, описанный в разделе [Как сбросить поддельные AirPods](/ru/articles/how-to-reset-fake-airpods), а затем снова откройте StarFun. В большинстве случаев прошивку можно установить повторно, начиная с 0%. В [руководстве по обновлению прошивки](/ru/articles/how-to-update-fake-airpods-firmware) описаны все чипсеты.

## StarFun не находит наушники?

Выполните следующие действия по порядку:

- **Сначала подключите их в настройках Bluetooth.** StarFun требуется, чтобы наушники уже были подключены к телефону.
- **Проверьте чип.** StarFun предназначен для моделей на Huilian. Для моделей на TigerBuilder (Airoha) используйте FlyCC, а для моделей на HR — BullSuper. Обычно определить чип можно, поочерёдно пробуя приложения со страницы [Полезные приложения](/ru/useful-apps) и проверяя, какое из них подключится.
- **Ни одно приложение не подключается?** Скорее всего, у вас очень низкокачественная копия на чипсете Jieli, который не поддерживается приложениями сообщества. Настоящие AirPods Apple тоже не будут реагировать на эти приложения.
- **Подключение постоянно прерывается?** Очистите кэш сопряжения, сбросив контроллер по инструкции из [руководства по сбросу](/ru/articles/how-to-reset-fake-airpods). Общие советы по устранению проблем с сопряжением приведены в статье [Поддельные AirPods не подключаются](/ru/articles/fake-airpods-wont-connect).
