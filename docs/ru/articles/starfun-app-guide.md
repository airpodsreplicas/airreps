# Руководство по StarFun APK: эквалайзер и прошивка для реплик AirPods на Huilian

StarFun — это приложение-компаньон для реплик AirPods на чипсетах **Huilian** (247, 277, 377 и 377H3). Оно выполняет для моделей на Huilian ту же роль, что [FlyCC](/ru/articles/flycc-app-guide) для моделей на Airoha и TigerBuilder: с его помощью можно настраивать эквалайзер и обновлять прошивку. Если у вас есть реплика на Huilian, например AirPods Pro 3 V7 Huilian или Pro 2 V5.4, установите StarFun.

> **Краткий ответ:** StarFun — это приложение для реплик AirPods на Huilian: AirPods Pro 3 V7 Huilian и V6 Huilian, AirPods Pro 2 V5.4 и V5.3 Huilian, а также AirPods 4 V2 Huilian. Скачайте приложение в формате APK для Android или из App Store для iOS по ссылке на странице [Полезные приложения](/ru/useful-apps#huilian). Используйте его для настройки эквалайзера, а прошивку обновляйте только в случае неисправности. Для моделей на TigerBuilder предназначено приложение FlyCC. Если ни одно приложение не подключается к наушникам, скорее всего, у вас недорогая копия на Jieli.

## Какие реплики используют StarFun

Ниже перечислены версии из руководства, в таблицах которых StarFun указано как приложение для настройки эквалайзера и параметров:

| Модель | Версия | Чипсет | Подключение iCloud |
| :--- | :--- | :--- | :--- |
| AirPods Pro 3 | V7 Huilian | Huilian 377H3 | ✅ |
| AirPods Pro 3 | V6 Huilian | Huilian 247 | ✅ |
| AirPods Pro 2 | V5.4 Huilian | Huilian 377 | ✅ |
| AirPods Pro 2 | V5.3 Huilian | Huilian 277 Pro Max | ✅ |
| AirPods 4 | V2 Huilian | Huilian 247 | ✅ |

В таблице AirPods 3 для версии V1.2 (Huilian A10) также указано приложение StarFun, но проверенные продавцы сейчас не предлагают AirPods 3.

Все пять моделей также поддерживают подключение iCloud. Эта функция доступна только репликам на Huilian, поэтому, если вы купили наушники, чтобы переключаться между устройствами Apple, вам понадобится StarFun. Сравните версии на страницах [Pro](/ru/version-info/pro) и [AirPods](/ru/version-info/airpods).

## Скачать StarFun для Android или iOS

StarFun доступно в двух версиях, ссылки на обе есть на странице [Полезные приложения](/ru/useful-apps#huilian):

- **Android:** [StarFun APK](https://airreps.link/starfun)
- **iPhone:** [StarFun в App Store](https://airreps.link/istarfun)

Версия для Android распространяется в виде APK, а не через Google Play. Если Android блокирует установку, включите для браузера или файлового менеджера параметр **Установка из неизвестных источников** (также называется **Установка неизвестных приложений**). Обычно он находится в настройках безопасности или специальных возможностей. Затем откройте скачанный файл `.apk` и нажмите **Установить**.

Прежде чем открывать StarFun, подключите наушники к телефону через обычные настройки Bluetooth.

## Настроить эквалайзер

Звучание эквалайзера может отличаться у разных продавцов, поэтому одна и та же версия может звучать по-разному в разных партиях. Для настройки эквалайзера на устройствах Huilian руководство рекомендует StarFun, так же как FlyCC — для TigerBuilder, а BullSuper — для HR. На AirPods 4 V2 Huilian пользовательские профили эквалайзера StarFun напрямую синхронизируются с iOS.

Не хотите настраивать всё с нуля? Участники сообщества делятся своими настройками эквалайзера в Discord (ссылка в конце руководства). Чтобы узнать, как звучат реплики «из коробки», прочитайте раздел [Качество звука](/ru/introduction/sound-quality).

## Обновить прошивку с помощью StarFun

Начните с главного правила сообщества: **если всё работает, ничего не трогайте.** Обновления прошивки выпускают в основном для исправления проблем, вызванных крупными обновлениями iOS, или серьёзных аппаратных неполадок. Если наушники без проблем подключаются и хорошо звучат, обновление лишь создаёт риск вывести их из строя.

Если обновление всё же необходимо, сначала выполните эту проверку безопасности:

1. Зарядите оба наушника и кейс выше 80%.
2. Во время обновления оставьте кейс подключённым к питанию.
3. Оставьте оба наушника в кейсе с открытой крышкой.
4. Не выключайте экран телефона, чтобы передача данных не прервалась.

Затем выполните обновление в StarFun:

1. Убедитесь, что наушники подключены к телефону, а крышка открыта.
2. Откройте **StarFun** и нажмите значок **Настройки / Прошивка**.
3. Сравните текущую версию прошивки с последней версией в облаке.
4. Нажмите **Обновить**. Приложение записывает блоки конфигурации один за другим.
5. После перезагрузки наушников удалите их из списка Bluetooth-устройств телефона и выполните мягкий сброс.

Используйте StarFun только с наушниками Huilian. Установка прошивки для другого чипсета может вывести наушники из строя, а прошивка для чипа Airoha немедленно выведет из строя плату Huilian.

Если обновление зависло на каком-либо проценте более чем на 5 минут, не закрывайте крышку и не вынимайте наушники. Повторите попытку или перезапустите приложение, не вынимая наушники. Если наушники полностью перестали отвечать, выполните полный сброс по инструкции в разделе [Как сбросить поддельные AirPods](/ru/articles/how-to-reset-fake-airpods), а затем снова откройте StarFun. В большинстве случаев прошивку можно установить повторно, начав с 0%. В [руководстве по обновлению прошивки](/ru/articles/how-to-update-fake-airpods-firmware) описаны все чипсеты.

## StarFun не находит наушники?

Выполняйте шаги по порядку:

- **Сначала выполните сопряжение в настройках Bluetooth.** StarFun требуется, чтобы наушники уже были подключены к телефону.
- **Проверьте чип.** StarFun предназначено для моделей Huilian. Для моделей TigerBuilder (Airoha) используйте FlyCC, а для моделей HR — BullSuper. Обычно чип определяют так: по очереди попробуйте приложения со страницы [Полезные приложения](/ru/useful-apps) и проверьте, какое из них подключится.
- **Не подключается ни одно приложение?** Скорее всего, у вас очень недорогая копия на чипсете Jieli, который не поддерживается приложениями сообщества. Настоящие AirPods от Apple тоже не реагируют на эти приложения.
- **Соединение постоянно прерывается?** Очистите кэш сопряжения, сбросив контроллер по инструкции в [руководстве по сбросу](/ru/articles/how-to-reset-fake-airpods). Общие сведения о проблемах с подключением — в разделе [Поддельные AirPods не подключаются](/ru/articles/fake-airpods-wont-connect).
