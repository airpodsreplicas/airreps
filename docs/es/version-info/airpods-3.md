# AirPods 3

::: tip
Esta línea de productos ya no recibe actualizaciones activas por parte de los fabricantes, ya que el desarrollo se ha centrado en modelos más nuevos. Las réplicas de AirPods 3 siguen siendo excelentes productos y continúan siendo opciones populares. Si buscas las funciones y mejoras más recientes, consulta [AirPods 4](/es/version-info/airpods-4).
:::

**Veredicto rápido:** el **V1E (Airoha 1562E)** es la réplica definitiva de AirPods 3 y el único modelo de esta gama que se sigue fabricando activamente — cuenta con cambio entre varios dispositivos, audio espacial con seguimiento de la cabeza, entre 7 y 8 horas de batería y carga inalámbrica MagSafe. Consulta los [enlaces de compra de AirPods 3](/es/links/airpods-3).

::: tip Características comunes de AirPods 3
Todos los modelos de AirPods 3 cuentan con: diseño contorneado de ajuste abierto con tallos más cortos, controles de reproducción mediante sensor de presión, detección en el oído, carga inalámbrica y compatibilidad con iOS 27 y una ventana emergente en la página de información. Ten en cuenta que las réplicas de AirPods 3 no cuentan con cancelación activa de ruido (ANC).
:::
