# AirPods 3

::: tip
This product line is no longer being actively updated by manufacturers, as development has shifted to newer models. AirPods 3 replicas are still excellent products and remain popular choices. If you're looking for the latest features and improvements, consider checking out [AirPods 4](/version-info/airpods-4).
:::

**Quick verdict:** the **V1E (Airoha 1562E)** is the definitive AirPods 3 replica and the only actively produced model in this lineup — featuring multi-device switching, head-tracking spatial audio, 7–8 hours of battery life, and MagSafe wireless charging. See the [AirPods 3 purchase links](/links/airpods-3).

::: tip Shared AirPods 3 Baseline
All AirPods 3 models feature: open-fit contoured design with shorter stems, Force Sensor playback controls, in-ear detection, wireless charging, and iOS 27 support with About page popup. Note that AirPods 3 replicas do not feature Active Noise Cancellation (ANC).
:::
