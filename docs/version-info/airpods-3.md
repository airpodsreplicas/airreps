# AirPods 3

::: warning Not currently stocked by trusted sellers
None of our trusted sellers currently list AirPods 3 replicas, as development and stock have moved to the newer open-fit **[AirPods 4](/version-info/airpods-4)**. This comparison is kept for reference.
:::

**Quick verdict:** the **V1E (Airoha 1562E)** was the definitive AirPods 3 replica — featuring multi-device switching, head-tracking spatial audio, 7–8 hours of battery life, and MagSafe wireless charging — but it is **not currently stocked** by trusted sellers. For an in-stock open-fit alternative, see the [AirPods 4 purchase links](/links/airpods-4).

::: tip Shared AirPods 3 Baseline
All AirPods 3 models feature: open-fit contoured design with shorter stems, Force Sensor playback controls, in-ear detection, wireless charging, and iOS 27 support with About page popup. Note that AirPods 3 replicas do not feature Active Noise Cancellation (ANC).
:::
