# AirPods 3

::: warning Obecnie niedostępne u zaufanych sprzedawców
Żaden z naszych zaufanych sprzedawców nie oferuje obecnie replik AirPods 3, ponieważ produkcja i zapasy przeniosły się na nowszy model z otwartą konstrukcją **[AirPods 4](/pl/version-info/airpods-4)**. To porównanie pozostawiamy do wglądu.
:::

**Werdykt w skrócie:** **V1E (Airoha 1562E)** to najlepsza replika AirPods 3 — oferowała przełączanie między wieloma urządzeniami, dźwięk przestrzenny ze śledzeniem ruchów głowy, 7–8 godzin pracy na baterii i bezprzewodowe ładowanie MagSafe — ale **obecnie nie jest dostępna** u zaufanych sprzedawców. Aby znaleźć dostępną alternatywę z otwartą konstrukcją, zobacz [linki do zakupu AirPods 4](/pl/links/airpods-4).

::: tip Wspólne cechy AirPods 3
Wszystkie modele AirPods 3 mają otwartą, wyprofilowaną konstrukcję z krótszymi nóżkami, elementy sterujące odtwarzaniem Force Sensor, wykrywanie umieszczenia w uchu, ładowanie bezprzewodowe oraz obsługę iOS 27 z wyskakującym okienkiem na stronie „To urządzenie”. Pamiętaj, że repliki AirPods 3 nie mają aktywnej redukcji szumów (ANC).
:::
