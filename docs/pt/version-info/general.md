::: tip Sobre os números de versão
Este sistema de numeração de versões foi criado pela comunidade AirReps para simplificar a identificação de produtos de diferentes fabricantes. Quando novos modelos de AirPods são lançados (como os AirPods Pro 2 ou Pro 3), a numeração das versões continua a partir dos números anteriores, em vez de começar do zero.

Fabricantes como TigerBuilder e Huilian usam seus próprios nomes de produtos (como "377super"), o que pode dificultar a comparação entre produtos de diferentes fabricantes. Nosso sistema de nomenclatura comunitário resolve esse problema ao fornecer um número de versão padronizado, facilitando a busca por produtos comparáveis entre fabricantes sem precisar memorizar dezenas de nomes diferentes.

**Observação:** os fabricantes não são os mesmos que os vendedores. Você não pode comprar diretamente dos fabricantes — você compra de vendedores que obtêm produtos desses fabricantes.
:::

**Todos têm:**

- Cancelamento Ativo de Ruído (ANC), modo Transparência e Áudio Espacial (somente nos modelos Pro e Max)
- Force Touch / controles por toque
- Detecção intra-auricular / óptica
- USB-C (modelos mais recentes) ou Lightning
- Página Sobre, alteração de nome e rastreamento por GPS (pelos Ajustes do iOS)
- Animação de pop-up no iOS

**O que falta em todos:**

Todos os modelos não têm o seguinte recurso:

- Rede Buscar (rastreamento preciso da localização quando longe dos seus dispositivos)

**Observação:** esta lista está ordenada dos modelos mais novos aos mais antigos. Um número maior geralmente, mas nem sempre, indica um modelo melhor. Pronto para comprar? Veja [como fazer um pedido](/pt/ordering/how-to-buy) com nossos [vendedores confiáveis](/pt/links/info).

::: details Por que comunidades semelhantes podem ter produtos mais novos do que os deste guia?
Os produtos listados neste guia são da mais alta qualidade e foram cuidadosamente selecionados para atender aos nossos padrões. Atualizamos a lista todos os dias para garantir que apenas os melhores produtos sejam incluídos. Outras comunidades podem ter padrões mais baixos e incluir produtos que não sejam de alta qualidade. Também é possível que usem um sistema de nomenclatura diferente para seus produtos, fazendo parecer que têm produtos mais novos do que os deste guia.

::: details Qual modelo é o melhor?
O modelo listado no topo é o mais recente, enquanto os outros modelos são versões anteriores. Para encontrar o melhor para você, considere fatores como seu orçamento, disponibilidade de envio e recursos desejados. Também é uma boa ideia pesquisar avaliações dos diferentes modelos e tomar sua própria decisão com base nessas informações.
:::

::: details Como posso determinar a versão de uma réplica que encontrei?
Não é possível determinar a versão de uma réplica sem usá-la de fato. Os números dos chips e as imagens fornecidas pelos vendedores não são indicadores confiáveis da versão de uma réplica. Perguntar aos vendedores se uma determinada réplica é de uma versão específica não fornecerá informações úteis, pois eles podem não entender a pergunta. Se estiver disposto a correr o risco, você pode comprar uma réplica aleatória. No entanto, para garantir que sabe exatamente qual modelo está adquirindo, é melhor comprar de vendedores verificados.
:::

::: details Como posso determinar qual chip está nos meus AirPods?
Para identificar o chip das suas réplicas de AirPods, consulte esta lista de [aplicativos úteis](/pt/useful-apps). Teste cada aplicativo individualmente para descobrir a qual deles seus AirPods se conectam. Isso ajudará você a identificar rapidamente o fabricante e o chipset. Observe que, se seus AirPods forem de categoria muito baixa, talvez não se conectem a nenhum dos aplicativos. Nesse caso, provavelmente usam o chipset Jieli.
:::

::: details Como posso determinar se meus AirPods são originais?
Para verificar rapidamente se seus AirPods são originais, conecte-os a um iPhone e acesse Ajustes > Geral > Sobre. Um par original mostra uma seção "AirPods", e o número de série nela deve corresponder ao número impresso na parte interna da tampa ([verifique aqui](https://airreps.info/aboutsection)). A ausência da seção AirPods significa que eles quase certamente são falsos — mas uma página Sobre funcional, por si só, não prova que são originais, pois réplicas mais recentes podem imitá-la. Para obter a lista completa de verificação (firmware, Áudio Espacial, embalagem e aplicativos de detecção de chips), leia nosso guia sobre [como saber se os AirPods são falsos](/pt/articles/how-to-spot-fake-airpods).
:::

::: details Os i9999, Superpods etc. são melhores que os Supercopy ou que os produtos listados no guia?
No passado, esses nomes eram usados para indicar atualizações ou melhorias em réplicas de AirPods. No entanto, os vendedores chineses começaram a usar esses nomes para fazer parecer que estavam oferecendo produtos mais novos ou melhores, quando na verdade estavam apenas vendendo os mesmos produtos de antes. Como resultado, esses nomes não têm mais significado e devem ser ignorados. Em vez disso, concentre-se nos recursos e na qualidade reais dos produtos ao tomar uma decisão de compra.
:::
