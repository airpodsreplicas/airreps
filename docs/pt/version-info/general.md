::: tip Sobre os números de versão
Este sistema de numeração de versões foi criado pela comunidade AirReps para simplificar a identificação de produtos de diferentes fabricantes. Quando novos modelos de AirPods são lançados (como AirPods Pro 2 ou Pro 3), a numeração das versões continua a partir dos números anteriores, em vez de recomeçar do zero.

Fabricantes como TigerBuilder e Huilian usam seus próprios nomes de produtos (como "377super"), o que pode dificultar a comparação entre produtos de diferentes fabricantes. O esquema de nomenclatura da nossa comunidade resolve esse problema ao fornecer um número de versão padronizado, que facilita encontrar produtos comparáveis entre fabricantes sem precisar memorizar dezenas de nomes diferentes.

**Observação:** fabricantes não são o mesmo que vendedores. Não é possível comprar diretamente dos fabricantes — você compra de vendedores que obtêm produtos desses fabricantes.
:::

::: details Como posso descobrir a versão de um clone que encontrei?
Não é possível descobrir a versão de um clone sem usá-lo. Os números dos chips e as imagens fornecidas pelos vendedores não são indicadores confiáveis da versão de um clone. Perguntar aos vendedores se determinado clone é de uma versão específica não será útil, pois talvez eles não entendam a pergunta. Se estiver disposto a correr o risco, você pode comprar um clone aleatório. No entanto, para ter certeza do modelo que está adquirindo, o melhor é comprar de vendedores verificados.
:::

::: details Como posso descobrir qual chip há nos meus AirPods?
Para identificar o chip dos seus clones de AirPods, consulte esta lista de [apps úteis](/pt/useful-apps). Teste cada app individualmente para descobrir a qual deles seus AirPods se conectam. Isso ajudará você a identificar rapidamente o fabricante e o chipset. Observe que, se seus AirPods forem de uma categoria muito básica, talvez não se conectem a nenhum dos apps. Nesse caso, provavelmente usam o chipset Jieli.
:::

::: details Como posso descobrir se meus AirPods são originais?
Para verificar rapidamente se seus AirPods são originais, conecte-os a um iPhone e acesse Ajustes > Geral > Sobre. Um par original exibe uma seção "AirPods", e o número de série nessa seção deve corresponder ao número impresso na parte interna da tampa ([Confira aqui](https://airreps.info/aboutsection)). Se a seção AirPods não aparecer, eles quase certamente são falsos — mas uma página Sobre funcional, por si só, não prova que são originais, pois réplicas mais recentes conseguem imitá-la. Para ver a lista completa de verificações (firmware, Áudio Espacial, embalagem e apps de detecção de chips), leia nosso guia sobre [como saber se os AirPods são falsos](/pt/articles/how-to-spot-fake-airpods).
:::

::: details i9999, Superpods etc. são melhores que Supercopy ou que os produtos listados no guia?
No passado, esses nomes eram usados para indicar melhorias ou atualizações de réplicas de AirPods. No entanto, vendedores chineses começaram a usar esses nomes para dar a impressão de que oferecem produtos mais novos ou melhores, quando, na verdade, estão apenas vendendo os mesmos produtos de antes. Por isso, esses nomes já não significam nada e devem ser ignorados. Em vez disso, considere os recursos e a qualidade reais dos produtos ao tomar uma decisão de compra.
:::
