# AirPods 2

::: tip
Esta linha de produtos não é mais atualizada ativamente pelos fabricantes, pois o desenvolvimento mudou para modelos mais recentes. As réplicas dos AirPods 2 ainda são excelentes produtos e continuam sendo opções populares. Se você procura os recursos e melhorias mais recentes, confira os [AirPods 3](/pt/version-info/airpods-3) ou os [AirPods 4](/pt/version-info/airpods-4).
:::

**Veredito rápido:** o **V3E (Airoha 1562E)** é a única réplica dos AirPods de 2ª geração que continua sendo produzida ativamente — oferecendo conectividade com dois dispositivos, personalização de EQ pelo aplicativo FlyCC, autonomia confiável de 5–6 horas e ótimo suporte ao iOS 27 por um preço imbatível. Veja os [links de compra dos AirPods 2](/pt/links/airpods-2).

::: tip Linha de base compartilhada dos AirPods 2
Todos os modelos de 2ª geração incluem: formato clássico original dos fones com haste longa, controles por toque (toque duplo para reproduzir/pausar/pular), detecção óptica intra-auricular, carregamento Lightning e suporte ao iOS 27 com pop-up na página Sobre. Observe que os fones de 2ª geração não têm ANC nem Áudio Espacial.
:::
