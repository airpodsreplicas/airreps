# AirPods 2

::: tip O desenvolvimento avançou
Esta linha de produtos não recebe mais atualizações ativas dos fabricantes, pois o desenvolvimento se voltou para modelos mais novos. As réplicas dos AirPods 2 continuam sendo excelentes produtos e seguem entre as opções mais populares. Se você procura os recursos e as melhorias mais recentes, confira os [AirPods 3](/pt/version-info/airpods-3) ou os [AirPods 4](/pt/version-info/airpods-4).
:::

**Veredito rápido:** o **V3E (Airoha 1562E)** é a única réplica dos AirPods Gen 2 que ainda é produzida ativamente — oferece conexão com dois dispositivos, personalização de EQ pelo app FlyCC, autonomia confiável de 5–6 horas e compatibilidade sólida com o iOS 27 por um preço imbatível. Veja os [links de compra dos AirPods 2](/pt/links/airpods-2).

::: tip Recursos comuns dos AirPods 2
Todos os modelos Gen 2 oferecem: encaixe clássico de fones com haste longa, controles por toque (toque duas vezes para reproduzir/pausar/pular), detecção óptica no ouvido, carregamento Lightning e compatibilidade com o iOS 27, incluindo janela pop-up na página Sobre. Observe que os fones Gen 2 não têm ANC nem Áudio Espacial.
:::
