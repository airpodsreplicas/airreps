# AirPods 3

::: warning Atualmente não disponíveis em vendedores confiáveis
Nenhum dos nossos vendedores confiáveis oferece réplicas de AirPods 3 no momento, pois o desenvolvimento e o estoque passaram para os mais recentes **[AirPods 4](/pt/version-info/airpods-4)** de encaixe aberto. Esta comparação foi mantida para referência.
:::

**Veredito rápido:** o **V1E (Airoha 1562E)** era a réplica definitiva dos AirPods 3 — com alternância entre vários dispositivos, áudio espacial com rastreamento da cabeça, 7–8 horas de duração da bateria e carregamento sem fio MagSafe —, mas **não está disponível no momento** em vendedores confiáveis. Para uma alternativa de encaixe aberto disponível em estoque, veja os [links para comprar AirPods 4](/pt/links/airpods-4).

::: tip Características comuns a todos os AirPods 3
Todos os modelos de AirPods 3 incluem: design contornado de encaixe aberto com hastes mais curtas, controles de reprodução Force Sensor, detecção no ouvido, carregamento sem fio e compatibilidade com o iOS 27, com janela pop-up na página Sobre. Observe que as réplicas de AirPods 3 não incluem Cancelamento Ativo de Ruído (ANC).
:::

Clique no nome de uma versão para ler as avaliações da comunidade.
