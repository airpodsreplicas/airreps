# Køb AirPods 3-kopier

AirPods 3-kopier giver dig en stilkformet pasform uden ANC. Sammenlign de tilgængelige versioner på siden [oplysninger om AirPods 3-versioner](/da/version-info/airpods-3), eller brug [quizzen](/da/quiz) hvis du skal vælge mellem modeller.

## Versioner og sælgere

::: info Ingen aktuelle opslag
Ingen af vores pålidelige sælgere har i øjeblikket AirPods 3-kopier. Se [sælgerlinks til AirPods 4](/da/links/airpods-4) for et lignende åbent design, der er på lager.
:::
