# AirPods 3

::: tip
Denne produktlinje opdateres ikke længere aktivt af producenterne, da udviklingen er skiftet til nyere modeller. AirPods 3-kopier er stadig fremragende produkter og er fortsat populære valg. Hvis du leder efter de nyeste funktioner og forbedringer, kan du se nærmere på [AirPods 4](/da/version-info/airpods-4).
:::

**Kort konklusion:** **V1E (Airoha 1562E)** er den definitive AirPods 3-kopi og den eneste aktivt producerede model i denne serie — med skift mellem flere enheder, rumlig lyd med hovedsporing, 7–8 timers batteritid og trådløs MagSafe-opladning. Se [købslinks til AirPods 3](/da/links/airpods-3).

::: tip Fælles AirPods 3-grundlag
Alle AirPods 3-modeller har: et kontureret design med åben pasform og kortere stilke, afspilningskontroller med Force Sensor, registrering i øret, trådløs opladning og understøttelse af iOS 27 med en popup på Om-siden. Bemærk, at AirPods 3-kopier ikke har aktiv støjreduktion (ANC).
:::
